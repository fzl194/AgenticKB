# 部署版本记录

应用部署版本只有一个真相源：仓库根目录的 `releases.json`。

## 发布新版本

1. 在 `releases` 数组顶部增加本次发布记录，包括版本号、日期、标题和变更列表。
2. 将 `current` 改成该版本号。
3. 提交代码后执行 `bash deploy-build.sh`。

构建脚本会用 `current` 生成镜像和离线包名称，例如：

```text
coremasterkb-app:1.0.0
cmkb-1.0.0.tar.zst
```

如果显式传入的 `CMKB_VERSION` 与清单不一致，构建会停止，避免部署包版本和页面版本不同。

版本号约定：修复使用 `1.0.1`，兼容的新功能使用 `1.1.0`，不兼容升级使用 `2.0.0`。

部署后，所有用户都可以在左侧导航最底部点击版本号查看当前发布内容。版本清单随镜像保存，不需要数据库或额外初始化。
