# AgenticKB 系统介绍页 · 设计定稿

日期：2026-11-13 · 状态：已与用户对齐，直接实施

## 目的与受众

单页对外介绍 AgenticKB 系统「有什么功能、现在做到哪、下一步去哪」。
受众：兄弟团队/同行 + 潜在使用者/新成员。口吻通俗，术语首现配白话解释。

**内容红线（用户明确要求）**：

- 不出现任何成果数字（域内规模、业界对标研究数字一律不用）
- 不介绍基于系统构建的应用案例
- 只介绍系统本身：功能模块罗列为主体，模块内标注状态（已上线/规划中）

## 交付物形态

- 单文件自包含 HTML：`docs/产品介绍/AgenticKB-系统介绍.html`
- 纯 HTML/CSS/JS，零外部请求、零框架、系统字体栈；可独立发送/离线打开
- 桌面优先（1280px+），窄屏自动降级单列；交互仅锚点导航+滚动高亮+轻量入场动画（尊重减动效设置）

## 页面结构（8 节，长页带顶部导航）

1. **Hero**（暗藏蓝 #0f172a，点阵网格+知识图谱装饰）— eyebrow `AGENTIC KNOWLEDGE BASE` + AgenticKB + 定位语「把领域知识从可阅读状态，编译为 Agent 可导航、可组合、可生成、可核查的运行时知识」+ 副题 + **L0材料→L1证据→L2对象(规划中)→L3制品 编译概念条**
2. **系统概览** — 三卡：它是什么 / 谁在用（三级角色+Agent 一等公民）/ 怎么交付（单容器·多域隔离·品牌定制）
3. **功能全景（主体）** — 18 实卡 + 2 幽灵卡（虚线边框「规划中」），按 5 域分组：
   - 知识生产：知识库与文档管理 / 一张网接入 / 挖掘范式编排 / 挖掘运行与质量门禁 / LLM 服务 / ⟍制作工作台(规划)
   - 知识消费：多路检索工作台 / 检索范式编排 / 检索记录与分析 / 文档结构图谱
   - 知识制品：表格制品 / Wiki 制品 / 版本·成员·用量治理 / ⟍知识对象层(规划)
   - Agent 接入：MCP 工具三件套 / 密钥与开放范围
   - 平台管理：角色与域隔离 / 概览与运营 / 系统设置与运维 / 平台指南
4. **核心流程** — 横向六步流程条（资料接入→挖掘加工→知识入库→检索与证据→制品沉淀→Agent 消费），上方双括线标「知识生产链/知识消费链」，每步标注对应模块
5. **特色能力 ×2** — ①检索链路管线图（授权→双路召回→RRF→重排→证据回填→去重→统一输出）+ 四类引用 chip（ev_/doc_/st_/art_）；②知识制品（金句 + 表格/Wiki 两子卡）
6. **Agent 接入** — 三工具卡（search_knowledge / get_knowledge / manage_files）+ 密钥与开放范围 + 简短伪调用块
7. **演进路线** — 垂直时间线 4 站：现在 v1.1.36（Agent=消费者）→ 制作工作台（「导出是送去检查，发布才是正式生效」）→ 知识对象层 L2（零代码建模·进认联改发退）→ Agent 共建（build_knowledge→自主闭环，「Agent 到草稿为止，发布权永远在人」）
8. **页脚** — 版本 · 单容器交付 · 内置平台指南 · 生成日期

## 视觉规范（延续产品 1.1.36 制品区语言）

- 设计令牌取自 `kb-ui/src/styles/variables.css`：accent #0891b2（soft rgba(8,145,178,.08)）；底 #f1f5f9 / 卡 #fff / hover #f8fafc；发丝线 #e2e8f0；文字三级 #0f172a/#64748b/#94a3b8；导航与 Hero 暗藏蓝 #0f172a；圆角 6/10/14/20
- 状态徽章：已上线=soft 青底实心点；规划中=虚线边框灰字；全景节首放图例
- 节头模式：eyebrow 英文小字（~10.5px/600/1.6px 字距）+ 中文标题 + 副题
- 图标：内联 SVG 单色线条（stroke 1.5），不引图标库；mono 字体（Consolas）用于引用前缀与工具名
- 风格基调：「工程蓝图×知识编译器」——发丝线工程文档质感，克制、精确，无渐变滥用
