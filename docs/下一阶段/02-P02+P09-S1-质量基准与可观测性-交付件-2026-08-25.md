# P02 + P09 S1：质量基准与可观测性交付件

日期：2026-08-25
分支：`codex/fix-p02-p09-quality-observability`
范围：P09 S1（为 P02 的真实 fallback 修复建立可观测质量基线）

## 已交付

1. `text/markdown` 与 `text/plain` 在解析时复用已读取的冻结源字节构造
   `char_coverage` 基准，不增加对象存储读取。
2. 首轮上线采用**只观测**语义：自动取得的基准会落库和进入快照，但暂不触发
   FAIL/FALLBACK，避免当前只有单一后端的生产链把历史 Markdown 归一化差异
   批量误判为失败。显式传入 `source_text` 的既有强制门禁契约保持不变。
3. Run 投影的 `metadata_json.quality_attempts` 逐项保存
   `attempt_index`、parser、decision、issues 和完整指标；因此未来的
   FAIL/FALLBACK attempt 即使不生成快照也可被观测。
4. 成功 Snapshot 的 `metadata_json.quality_metrics` 保存同一份完整指标，包含
   `char_coverage`、`table_grid_consistency`、空容器/空页信号和 warning 分布。
5. PostgreSQL 与内存 ParseRunRepository 均新增无状态迁移的 metadata 更新契约。
