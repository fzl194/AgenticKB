# P02 S3：真实 Fallback 链交付件

日期：2026-08-26
分支：`codex/fix-p02-real-fallback`

## 已交付

- 新增可运行的本地 `pdf_text_layer` 适配器，使用 pdfminer 提取 PDF 文本层，
  再复用 PdfNormalizer 形成 Parse IR。
- Registry 注册顺序固定为 `native_pdf → pdf_text_layer`；生产
  `default_plan_factory` 与 ParserRouter 均由同一顺序生成 PDF 主备链。
- ParserRouter 对扫描 PDF 保持空 fallback：没有文本层时文本层适配器无效，
  只保留 OCR 需求信号，避免伪降级。
- Quality Gate 产生 REPAIR 且计划仍有后端时，Operator 将其推进为 FALLBACK；
  没有备用后端时继续保留 WARN 兼容语义。
- 验证 fallback 成功的 Run 仍按 primary 指纹命中既有幂等探针，不重复解析。
