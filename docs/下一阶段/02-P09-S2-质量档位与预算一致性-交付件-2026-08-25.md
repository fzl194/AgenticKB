# P09 S2：质量档位与预算一致性交付件

日期：2026-08-25
分支：`codex/fix-p09-quality-profile`
范围：P09 S2 的 qualityProfile 生产接线与 AttemptBudget 默认值统一。

## 已交付

1. `DocumentParseFacade.default_plan_factory` 将 `qualityProfile` 写入冻结的
   `ParsePlan.quality_profile`；Plan 只接受 `default`、`strict`、`lenient`，
   未知值在编排前拒绝。
2. `DocumentParseService` 每次 backend attempt 按该冻结档位选择
   `QualityGate`，不再固定使用无档位的默认 Gate。
3. 阈值表：

   | 档位 | 覆盖率硬阈值 | 覆盖率目标 | 证据可定位率 |
   |---|---:|---:|---:|
   | default | 0.85 | 0.95 | 0.80 |
   | strict | 0.95 | 0.99 | 0.90 |
   | lenient | 0.70 | 0.70 | 0.00 |

4. 灰度语义保持安全：default/lenient 对 S1 自动取得的文本基准继续只观测；
   strict 明确让该基准参与门控。调用方显式传入 `source_text` 时，三个档位
   均按各自阈值强制评估。
5. `AttemptBudget.max_backend_attempts` 契约默认值由 2 统一为 3，和工作流
   参数、迁移默认值一致，避免真实 fallback 链接入后出现预算语义分裂。
