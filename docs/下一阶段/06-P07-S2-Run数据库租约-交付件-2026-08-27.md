# P07 S2：Run 数据库租约交付件

日期：2026-08-27
分支：`codex/fix-p07-run-leases`

## 已交付

- `mining_runs` 增加 `worker_id`、`lease_until`、`heartbeat_at`、`attempt_no`，并建立有效租约查询索引。
- 执行入口在 ingest 前原子认领；另一执行器已认领时直接退出，不会并发执行同一 Run。
- 同域认领在单条 CAS 中串行化，并拒绝同域已有有效租约的 Run，避免多实例双跑。
- 执行线程每 30 秒续租；续租失去所有权后，下一检查点停止推进；退出时按 worker_id 释放租约。
- 启动恢复只中断无租约或已过期租约的 queued/running Run，不再误伤其他实例的活跃执行。
