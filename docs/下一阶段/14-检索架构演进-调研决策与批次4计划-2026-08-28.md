## 2. 四项架构决策（2026-08-28 用户拍板，已录入 00-README 第 9 节 + memory）

| 决策点 | 结论 |
|---|---|
| 链路统一 | **只保留范式编排链路**。固定链路（SearchService 九步管线）在四能力算子化 + 官方默认范式复刻后**彻底删除**，不留兼容期（用户原话："需要清除掉的，我只需要检索范式的检索"） |
| 范式与 KB 关系 | **菜谱+运行时范围**两层解耦：范式=菜谱不含 KB；KB 可设默认范式；搜索时现场指定库组合。范围解析优先级：**显式指定 > 库级默认 > 领域默认 > 官方默认**。scope_resolve 演进：图内可写死（专属用法）或留空（运行时注入） |
| MCP 用户化 | **单实例 + 用户级接入密钥**：UI 生成/吊销密钥、管理开放库范围与工具描述；Agent 持钥 → MCP 透传用户身份 → serving 按用户授权 |
| MCP 工具族 | `list_knowledge_bases` / `search_knowledge` / `list_documents` / `get_document` / `get_segment_fulltext` |

**实施顺序（已拍板）**：检索就绪（批次4 原计划）→ A（身份与绑定模型）→ B（MCP 工具族+管理页）→ C（链路统一+固定链路删除）。

## 3. 现状调研结论 A：Java serving 检索（双链路/范式/KB scope）

服务：Spring Boot，端口 8081，默认域 cloud_core_network。**两条链路并行、互不影响**。

### 3.1 固定检索链路（legacy，将删除）
- 入口 `POST /api/v1/search`（SearchController.java:22-42；请求体 SearchRequest：query/scope/entities/debug/domain/channel/mode/**kbIds**，身份 X-KB-User header）
- SearchService.search 九步（SearchService.java:125-466）：domain 解析 → KB 授权（KbAccessService）→ 并行查询理解/HyDE/多查询扩展 → RetrievalRouter 路由（lexical_bm25/dense_vector/entity_exact/entity_graph 四路线+weighted_rrf 融合+rerank 级联）→ resolveActiveScope → **树导航+语义缓存+变体嵌入** → 多路召回（RetrievalOrchestrator）→ 融合/hydrate/rerank/组装
- FTS 三级降级（FtsRetriever.java:61-220）：tsvector → pg_trgm → LIKE，每级二次重试
- **范式链路缺的四能力**（C 阶段要算子化）：树导航（TreeNavigator）、语义缓存（SemanticCacheService）、多查询扩展（MultiQueryExpander）、重排级联+后处理（RerankPipeline.java:58-166 级联/降权/近重去重）

### 3.2 范式编排链路（operator/paradigm，唯一保留）
- 入口三个：ParadigmController（CRUD/publish/rollback/binding/`POST /api/v1/paradigm/{id}/search`/`GET /resolve`/`GET /mcp-catalog`）、ParadigmRunController（inline run/validate）、`GET /api/v1/operator/catalog`
- 执行：ParadigmExecutionService.run → ParadigmCompiler（7 项编译校验）→ ParadigmExecutor（拓扑波并行+虚拟线程，错误按 ErrorPolicy）→ shape 输出（assemble 终点=contextPack / collect 终点=candidates）
- **18 算子**：request_input；query_embed/hyde/query_understanding/multi_query；**scope_resolve**；dense_vector/fts/entity_exact/graph_expand；rrf/weighted_rrf/identity；model_rerank/llm_rerank/score_rerank；collect/assemble
- 数据表（控制库 defaultDataSource，`src/main/resources/db/operator/001+002`）：`operator_paradigm`（draft_graph_json/current_version/status）+ `operator_paradigm_version`（不可变快照）+ 域绑定列（bound_domain/is_default + 每域至多一个默认的部分唯一索引）
- 绑定校验链（ParadigmBindingService.bind）：域存在 → 已发布 active → servable（assemble 终点）→ **图内 KB 匿名可读预检**（MCP 无身份，绑定期即校验）
- **范围算子（KB 指定的关键）**：ScopeResolveOperator，params.kbIds: string[]（x-widget: kb-picker）。**kbIds 设计期冻结在图里**（发布即固化，非请求参数）；支持多 KB 数组+多 scope 节点；执行时仍按 X-KB-User 重新授权。范式执行请求**没有任何 KB 参数**（ParadigmRequests.toRunArgs 只有 query/domain/channel/debug）
- 前端已有完整范式编辑器（kb-ui/src/views/paradigm/ + api/operator.ts：catalog/mcp-catalog/CRUD/publish+bind/dryrun/run，11 个模板）
- 复用度：FTS/scope/assemble/reranker-bean 完全复用；dense SQL 分叉（operator 侧多 textKind）；融合与级联逻辑独立实现

### 3.3 KB 在检索侧
- 统一入口 `resolveActiveScope(domain, channel, kbIds)`（AssetRepository.java:111-116）：kbIds 空=域级 release；非空=resolveKbScope（**绕过 release**，per-document 取 KB 最新 validated/published build 的 active 快照，DISTINCT ON；AssetBuildDocumentSnapshotMapper.xml:36-58，已含批次1 加的软删过滤）
- 授权 KbAccessService.authorize：public OR owner OR kb_members；匿名（MCP）仅 public；任一不可读整单拒（不泄露哪个）
- KB 属于 domain（knowledge_bases.domain NOT NULL）；范式绑定域后图内 KB 必须同域
- fulltext/raw 钻取：paradigmId 或 kbIds 二选一（ScopeResolver.java:58-94）

## 4. 现状调研结论 B：MCP 服务

- **本体**：Python 官方 SDK FastMCP 1.x（pyproject 声明 fastmcp>=2.0 与实际 import 不一致——已知债务）；cmkb 容器 supervisord 托管（非独立容器），streamable-http `POST /mcp`（JSON-RPC 2024-11-05，Mcp-Session-Id 会话），端口 9000 默认仅宿主回环
- **零鉴权零用户**：无 token/无白名单；**从不发 X-KB-User** → serving 眼里是匿名 → **只能搜 public KB**；全局单实例共享
- **仅 2 个 tool**：`search_knowledge`（query/domain 必填+paradigm?/scope?/entities?；scope/entities 传了也不生效只回 ignored_args）+ `get_segment_fulltext`（refs 上限 50，paradigm_id 必须回传）；health_check 已实现未暴露
- 路由逻辑（client.py:103-122）：显式 paradigm → catalog 解析（30s TTL）→ `/paradigm/{id}/search`（失败不回落）；否则 `/paradigm/resolve?domain=` → bound 走范式 / unbound 回落 legacy `/api/v1/search`；kill switch `MCP_PARADIGM_ROUTING`；范式响应拍平成 legacy 外壳+`_retrieval` 元数据
- **无管理界面/API**：配置全环境变量（SERVING_URL/超时/TTL/`MCP_RAW_FILE_BASE_URL`）；工具描述硬编码在代码（改需重启）
- 前端仅四处关联：范式列表"Agent 可见性"列（mcp-catalog hidden 原因码）、绑定对话框 is_default、绑定错误文案、Dashboard channel 统计（注意：MCP 不发 channel，流量落 default_channel，日志无法区分 MCP）
- 设计文档：docs/mcp-paradigm-routing-design.md、mcp-dynamic-paradigm-tools-design.md、mcp-paradigm-tools-dev-plan.md
