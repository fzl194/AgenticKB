## 0. 目标形态（用户口径）

**检索只有一个世界：知识库 × 检索范式。**

```
左侧导航                          知识库详情
├─ 知识库                          ├─ 文件
├─ MCP 接入（新，全员）             ├─ 检索（新）：选/绑本库检索范式
│    ├─ Agent 接入配置 JSON 一键复制 │    + 搜索框直接测试本库检索
│    ├─ 密钥（一人一个）            ├─ 成员
│    ├─ 开放哪些 MCP 工具（开关）    ├─ 挖掘
│    ├─ 检索工具开放哪些库（勾选）   └─ 设置
│    └─ 工具提示词/描述（可编辑）    （旧"检索"左侧菜单删除；老固定链路删除）
```

- 每个知识库怎么检索 = 库自己绑的范式决定（设置/检索 tab）
- MCP 是用户级：工具开关 × 开放库 × 提示词，全在 MCP 页自管
- **检索只剩范式链路**：网页端测试、MCP、未来一切调用全走范式执行

## 2. 批次7：MCP 工具族与管理页（紧随批次6）

### 2.1 MCP 独立 tab（kb-ui，全员可见）
自上而下：
1. **Agent 接入配置 JSON**：按当前部署地址 + 本人密钥拼好的完整配置（MCP streamable-http 端点 + Authorization 头），一键复制；提供 dify/通用两种格式
2. **密钥**：状态/重新生成（旧钥立即失效）
3. **工具开关**：每个工具可单独开放/关闭（默认全开）
4. **检索工具的开放库**：勾选（检索范围=开放库 ∩ 本人权限）
5. **提示词与工具描述**：MCP 对 Agent 的自我介绍（instructions）+ 每个工具的描述文字，可编辑（留空=默认文案）；生效于 tools/list 动态渲染

### 2.2 MCP 工具族六件套（mcp_server）
| 工具 | 说明 | 数据源 |
|---|---|---|
| search_knowledge | 检索（已有，按开放库路由） | serving 范式执行 |
| list_knowledge_bases | 我开放的库清单（id/名称/文档数/就绪度） | mining KB API（新增内部端点） |
| list_documents | 某库的文件列表（分页，名称/状态/大小） | mining KB 文档 API（新增内部端点） |
| get_document | 某文件的结构化内容（切片级） | mining 知识读路径（新增内部端点，软删过滤） |
| get_segment_fulltext | 切片原文（已有） | serving |
| upload_document | 上传文件入库（走批次2b/2c 上传通道；**不自动触发挖掘**，页内提示去界面点挖掘——自动挖掘与否留小决策） | mining KB 上传 API |

- 全部工具强制密钥；工具开关在鉴权响应里下发（verify 返回 open_tools），未开放的工具不出现在 tools/list、调用即拒
- **tools/list 动态化**：按用户配置渲染（开关×描述文案）——需把 FastMCP 1.x 静态注册改造为自定义 list_tools/描述注入（批次5 遗留的"tools/list 匿名可见"一并收口：无钥连清单都拿不到）

### 2.3 配置存储（Python 域库）
- `mcp_access` 扩列：`open_tools jsonb`、`instructions text null`、`tool_descriptions jsonb`
- verify 响应扩：open_tools/instructions/tool_descriptions（MCP 免二次查）
