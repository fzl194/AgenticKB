## 4. 本次新沉淀的坑（永久）

- **共享快照跨文档**：同内容多文档复用 snapshot 时，doc_key 前缀的表示 ID 会在重挖时漂移而 embeddings 挂旧 id——ID/canonical 一律锚定 snapshot（本次已修，设计约定：文档归属读 `asset_document_snapshot_links`）
- **启动双写者**：`v2-rollout` 迁移补缺省参数与预置漂移刷新互不知晓→每次重启 +2 版本；模板必须与 `_NEW_SEGMENT_DEFAULTS` 显式同值
- readiness 门禁的 action 过滤必须在 `classify_documents` **之后**（分类前 KB 决策 action 未定）
- readiness 查询在 build 事务外读已提交行无问题，但检索紧随 run 完成有秒级 build 可见性竞态（E2E 需缓冲）
