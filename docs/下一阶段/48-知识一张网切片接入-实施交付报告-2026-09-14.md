## 四、内网验收清单（M5，用户执行）

1. **配置**：复制 `main_control_service/config/system/onenet.example.yaml` 为 `onenet.yaml`，填 appid.txt 的 app_id/static_token（或设 ONENET_APP_ID/ONENET_STATIC_TOKEN 环境变量）；重启 mining 服务。
2. **迁移**：部署 016/012 两个 schema 文件（deploy-sync 包外，需在库上执行——见部署注意）。
3. **UDG 子集冒烟**：管理页查询「UDG」→ 选 DOC1101733708 → 摸底（应 157,866 切片）→ 加载章节树 → 勾选「IPFD-010000 接口与链路」子树 → 导入 → 等状态 done → 记录详情核对文件数与目录树。
4. **β 规则校准**（重点）：抽查还原文件的 path[-2] 归属是否符合预期；不符则记 file_path 样例，调 beta-1 参数（不动代码）。
5. **挖掘验证**：公共库自动挖掘 Run 成功；检索单元/向量数 > 0；检索命中一张网内容并显示章节路径。
6. **引用链路**：业务库「一张网」tab → 展开 UDG → 勾选文件 → 引用 → 本库检索命中 → markdown 预览 → 取消引用后检索收窄。
7. **重同步**：上游版本变化后点「重同步」→ 观察 diff 报告与文档更新/下线；引用方自动收窄。
