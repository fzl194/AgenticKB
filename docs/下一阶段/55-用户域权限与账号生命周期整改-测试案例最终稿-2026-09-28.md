1. 只在测试环境或明确可清理的测试账号/知识库上执行。

5. Editor 的成员管理权限沿用当前版本语义，本批不改变。

## 13. 只读数据库核验 SQL

### 13.1 active 普通用户零域必须为 0

```sql
SELECT count(*) AS violations
FROM kb_users u
WHERE u.status = 'active'
  AND u.deleted_at IS NULL
  AND u.site_role <> 'admin'
  AND NOT EXISTS (
      SELECT 1 FROM user_domains ud WHERE ud.user_id = u.id
  );
```

### 13.2 active KB 授权硬域边界必须为 0

```sql
WITH violations AS (
    SELECT u.id AS user_id, kb.id AS kb_id, kb.domain
    FROM knowledge_bases kb
    JOIN kb_users u ON u.id = kb.owner_id
    WHERE kb.status = 'active'
      AND u.status = 'active'
      AND u.deleted_at IS NULL
      AND u.site_role <> 'admin'
      AND NOT EXISTS (
          SELECT 1 FROM user_domains ud
          WHERE ud.user_id = u.id AND ud.domain = kb.domain
      )
    UNION ALL
    SELECT u.id, kb.id, kb.domain
    FROM kb_members km
    JOIN knowledge_bases kb ON kb.id = km.kb_id
    JOIN kb_users u ON u.id = km.user_id
    WHERE kb.status = 'active'
      AND u.status = 'active'
      AND u.deleted_at IS NULL
      AND u.site_role <> 'admin'
      AND NOT EXISTS (
          SELECT 1 FROM user_domains ud
          WHERE ud.user_id = u.id AND ud.domain = kb.domain
      )
)
SELECT count(*) AS violations FROM violations;
```

### 13.3 deleted 用户不应保留权限边

```sql
SELECT u.id, u.username,
       (SELECT count(*) FROM user_domains ud WHERE ud.user_id = u.id) AS domains,
       (SELECT count(*) FROM kb_members km WHERE km.user_id = u.id) AS memberships,
       (SELECT count(*) FROM mcp_keys mk
        WHERE mk.user_id = u.id
          AND (mk.status = 'active' OR mk.deleted_at IS NULL)) AS visible_or_active_keys
FROM kb_users u
WHERE u.deleted_at IS NOT NULL;
```

每行 `domains=0`、`memberships=0`、`visible_or_active_keys=0`。

### 13.4 最少一个 active 站点管理员

```sql
SELECT count(*) AS active_site_admins
FROM kb_users
WHERE site_role = 'admin'
  AND status = 'active'
  AND deleted_at IS NULL;
```

结果必须 `>= 1`。
