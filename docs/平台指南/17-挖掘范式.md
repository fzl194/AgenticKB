# 17 · 挖掘范式（挖掘 Workflow）

页面：`/mining/workflows`（列表）、`/mining/workflows/:id`（编排器）｜仅站点管理员

## 这是什么

挖掘范式决定**一次挖掘 Run 跑哪些阶段**（解析→抽取→入库…）——"进料怎么加工"。与检索范式（第 18 章）是两个不同的东西。

核心特性：

- **全局共享**，不随域切换；
- 草稿使用 revision **乐观锁**；
- **已发布版本不可变**：发布即冻结 `workflow_id + workflow_version + graph_hash + manifest`，之后按批次选择**精确版本**执行；
- 上传文件挖掘时不选会用**系统默认** Workflow；
- 旧请求不传 Workflow 自动使用系统 FULL Pipeline。

## 列表页

| 列 | 说明 |
|---|---|
| 名称 | 带「系统默认」/「系统」标签 |
| 描述 | — |
| 草稿 | `r<revision>` 当前草稿乐观锁版本 |
| 当前版本 | `v<n>` 或"未发布" |
| 状态 | 已发布 / 已归档 |

操作：**编排/版本**（进编辑器）、**复制**、**归档**。新建弹窗标题为「新建挖掘范式」（名称+描述）。

## 编排器（画布）

- **左侧算子面板 → 双击或拖拽到画布**；节点带"当前必需 / 可选 / 禁用"标记，固定骨架节点不可删；
- **连线**：从节点拖到下游建立执行顺序；
- **保存草稿**：存在 revision 冲突时提示"放弃本地并加载远端"或"返回当前草稿"；离开页面有未保存改动会确认；
- **发布新版本**：先过**服务端校验**（未通过不能发布）；版本未改变时要求显式重新发布；
- **版本历史**：可查看/恢复历史版本——**历史版本只读**，恢复会生成新的草稿 revision（不覆盖当前发布版）；
- 调试辅助：复制本地 JSON。

## 与挖掘的关系（速查）

| 场景 | 行为 |
|---|---|
| 绑定范式 | 库详情「挖掘」tab 顶部选择（仅拥有者/编辑者可改） |
| 版本冻结 | 每次挖掘 Run 记录所用的精确版本，重放可追溯 |
| 范式变更 | 换范式/版本/图变了，挖掘时**自动强制重挖** |
| 已发布 manifest | 编译期冻结算子参数——改算子默认值对已发布版本无效，需重新发布工作流或靠域包策略覆盖 |
| 应急回退 | 显式配置 `MINING_RUN_SUBMISSION_ENGINE=legacy`（完整回退与回滚步骤见 `docs/mining-workflow-rollout-runbook.md`） |

## 可选算子：图片图注生成（figure_caption_generate）

**功能**：挖掘时对文档里**没有原生图注**的图片（PPTX 内嵌图，PPTX 之外格式暂未支持字节抽取）调用多模态大模型（VLM）生成一句中文图注，作为独立 figure 切片**追加**进切片库——图片内容从此可被检索命中。**实验算子、FALLBACK 语义**：LLM 失败/无图/格式不支持都只降级，绝不阻断基础资产入库。

**启用**（默认不进任何官方预置，存量零影响）：

1. `llm_service` 的 `main_control_service/config/system/llm_service.yaml` 顶层（`active_model` 旁）设 `vision_model: <模型名>` 指向模型列表里的多模态条目（未设时回落 `active_model`；`active_model` 不用动——按模型名路由）；
2. 挖掘范式页直接**新建「图文混合资产」预置**（官方第 5 套预置＝标准混合链 + 图片图注生成，无需手动编排），或复制 `hybrid_assets` 自定义并在「切片编译」之后插入**图片图注生成**节点；节点参数：`model`（**留空＝用 llm_service 的默认视觉模型**，填写则覆盖）/`maxFigures`（默认 20）/`minImageBytes`（默认 1024，过滤装饰小图）；发布并在库详情绑定该范式。默认视觉模型名可经 `GET /api/v1/models/vision-default` 巡检（挖掘子服务启动时读取，改配置后需重启挖掘子服务）。

**机制速览**：图注结果写缓存表 `asset_figure_caption_cache`（键=源哈希+解析指纹+图元素+模型+提示词版本——重跑/换范式命中缓存近零成本）；追加切片 `segment_index` 从 1,000,000 起（与主链命名空间隔离，重切不误伤）；切片 `metadata.caption_source='vlm'` 可审计。OCR/扫描件明确**不支持**。
