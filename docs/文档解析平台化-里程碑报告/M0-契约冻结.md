## 4. 关键决策摘要（详见 ADR-0002/0003）

- **O1**：Snapshot 指纹**不含 document_id**（`domain+raw_hash+parser_fp+workflow_hash+compiler_fp`），跨文档复用经 snapshot_links（SRS §8.3）。
- **O2**：粒度 = element + table cell 必存；TXT/Markdown 也存行范围（支撑 §A01）；word-level 默认关。
- **D-001**：契约层用 frozen dataclass + Protocol（沿用 contracts Layer-1），**不用 Pydantic**；校验用 jsonschema。
- **D-002**：Object Store Port 双 adapter——Fake（测试/开发）+ MinIO（生产）；业务只依赖 Port。
- **D-004**：M0 只加表/列，不改任何读写；FK 推迟 M1，UNIQUE/CHECK 立即生效。
- **D-017**：nullable object_version_id 用 `COALESCE(...,'')` 表达式唯一索引统一 NULL 语义。

## 5. 对 SRS 的偏离

均为「SRS 未规定实现细节，按其原则补充」，已逐条记入 ADR-0003 D-007~D-019，无违反 SRS 不变量之处。两处需注意的「字面偏离」：

1. SRS §15.2 字面建议指纹含 `document_id`——本实现按 §8.3 跨文档复用语义**不含**（O1）。
2. SRS §15.2 提「Pydantic contract」——本实现按 contracts Layer-1 零依赖约定用 **frozen dataclass + jsonschema**（D-001）。
