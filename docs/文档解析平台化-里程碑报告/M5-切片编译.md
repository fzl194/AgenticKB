## 1. 业务目标（用户语言）

把入库的知识快照**切成检索能用的段落**，并让用户在前端**看见每个文件的
结构化数据**：

| 保证 | 实现 |
|---|---|
| 按结构切，不按字数盲切 | 段落跟着章节走（携带"章 › 节"标题链）；表格切"整表 + 每行"（行自动带表头和表名）；图带图题；页眉页脚不进知识 |
| 每条切片能回原文 | 切片 ↔ 原文元素/证据 span 多对多映射落库（检索命中可定位到页/区域/单元格） |
| 切片策略升级不重新花钱 | A08 闭环：策略变化 → 复用快照 IR 重切 → 新快照；旧快照与旧切片原样保留 |
| 现有下游无感切换 | 兼容投影：切片落旧表（asset_raw_segments），类型收敛到 legacy 白名单，现有增强/向量化/检索环节零改动 |
| 前端看得见 | 文档预览页新增「结构化数据」页签：大纲树/表格网格/切片列表（带标题链）/出生证明（质量/版本/管线指纹） |

## 3. 交付物

### 3.1 契约（M5.1）
- `contracts/segment_compiler.py`：`SegmentPolicy`（**范式构建器头部节点
  可暴露的参数档位**：粒度 max/min tokens、同链合并、标题链注入、表格
  视图 whole/rows/both、图注开关；frozen + 指纹）、`compiler_fingerprint()`
  （编译器版本 + 策略）、`SegmentElementLink`、`CompiledSegment`。

### 3.2 编译器（M5.2，`segment_compiler/compiler.py`）
- 标题栈维护层级链；最内层标题文本并入节首切片（§5.3）；
- 同链相邻段 token 上限内合并；单体超限按字符二分（char_range 留痕）；
- 表格 rows 视图 = 整表 + 逐数据行（表头数组 + caption + 行号，links 到
  该行 cell 证据 span）；纯标题节独立成段；家具过滤。

### 3.3 落库 + 兼容（M5.3）
- `to_raw_segment_data` 兼容投影：heading_chain→section_path、links→
  source_offsets_json、metadata→structure_json；**新链类型收敛到 legacy
  block_type 白名单**（table_row→table / figure→image 等——DB CHECK 与
  下游 switch 分支零改动，行细节保留在 structure_json）。
- 011 DDL（双方言）：asset_raw_segments + compiler_fingerprint 列、
  asset_segment_element_links 表；`PgSegmentStore`（快照级替换语义）+
  `MemorySegmentStore`；读回逆映射。

### 3.4 A08 重切闭环（M5.4）
- `SnapshotCommitService.commit(compiler_fingerprint=…)`：策略指纹进
  snapshot_fingerprint → 策略变化产**新快照**。
- `SnapshotRecompileService`：旧快照 → 读回 IR（不重新解析）→ 新策略
  指纹提交新快照（旧快照保留 + recompiled_from 可见性）→ 新快照下重切。

### 3.5 只读 API + 前端（M5.4）
- `GET /api/knowledge/documents/{id}/parse-result`：大纲/元素/表格摘要/
  切片预览/出生证明（快照指纹、来源对象+revision、解析与切片管线、
  质量结论）；`ParseResultReadService` + `latest_for_document` 仓储方法
  （memory/PG）。
- kb-ui 文档预览页新增「**结构化数据**」页签（系统组件风格）：快照
  出生证明卡 + 大纲树 + 表格网格（带表头列名）+ 切片折叠列表（标题链
  路径 + 类型标签）；404 = 未走新链更新知识，显示引导文案。
